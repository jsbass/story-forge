## Engine: SugarCube 2 - designs it handles well

For blockers or risks on SugarCube, propose a design built from this project's loop modules (`forge loops types`) or custom code:
- real-time action → a turn-based `minigame` `skill_check`, or a short timing-window widget written as custom code
- free movement / open world → the `explore` module's hub-and-spoke map
- physics → describe outcomes in text, decided by a `skill_check`
- puzzles with items → `inventory` recipes; codes → `minigame` locks
- very large stories → split into chapters, keep passages lean (the whole story ships in one HTML file)
